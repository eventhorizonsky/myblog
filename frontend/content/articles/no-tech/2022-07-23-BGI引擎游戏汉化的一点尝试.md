## 1 起因

组里有翻译大佬想要汉化名字叫宝石学院的GAL

![](http://img.ezsky.xyz/i/2022/07/23/12zjk5u_0.png)

本身只是想帮着找找有没有大佬写好的解封包工具，没想到后来会熬三个大夜来研究，整理一下这几天的结果。

## 2 文本汉化

首先，用GARBRO在含有文本的arc文件上右键——提取

![image-20220724002802437](http://img.ezsky.xyz/i/2022/07/24/gpikj_0.png)

得到剧本文件

![image-20220724002858520](http://img.ezsky.xyz/i/2022/07/24/h9ub6_0.png)

下载两个[PY脚本](https://github.com/yanhua0518/GALgameScriptTools)（因此要有python环境，没有可以参照[这个](https://www.liaoxuefeng.com/wiki/1016959663602400/1016959856222624)安装）

![image-20220724001713653](http://img.ezsky.xyz/i/2022/07/24/a82rz_0.png)

先通过记事本之类的更改`BGIScriptRepacker.py`中的这两个`GBK`为`UTF-8`

![image-20220724002423399](http://img.ezsky.xyz/i/2022/07/24/eg53h_0.png)

将两个py文件放在剧本文件的同目录下（方便写路径）

在文件夹空白处右键（或者ctrl+右键）在终端中打开

![image-20220724003245604](http://img.ezsky.xyz/i/2022/07/24/jciqc_0.png)

输入以下代码对ja_01文件解包成txt（或者将ja_01拖动到该py文件上面）

```bash
python BGIScriptDumper.py ja_01
```
对得到的txt文件汉化后（不要修改txt文件的编码）

![image-20220724003537505](http://img.ezsky.xyz/i/2022/07/24/l30nv_0.png)

在刚刚的终端输入（ja_01是源文件，ja_01.txt是修改好的文本，1是要生成的文件名）

```bash
python BGIScriptRepacker.py ja_01 ja_01.txt 1
```
如果顺利，命令台的输出应该是这样的

![image-20220724004001572](http://img.ezsky.xyz/i/2022/07/24/nulhp_0.png)

将最后生成的文件`1`改成源文件的名字`ja_01`放在和启动游戏的exe相同目录

![image-20220724004137477](http://img.ezsky.xyz/i/2022/07/24/oneq8_0.png)

这样，游戏程序就可以读取到汉化后的文本了。

## 3 修改字符编码

因为我们修改了文本为UTF-8编码，因此也需要修改游戏程序的编码读取方式，不然就会变成乱码

需要用到[Ollydbg](https://down.52pojie.cn/Tools/Debuggers/)这个软件

![image-20220724004609881](http://img.ezsky.xyz/i/2022/07/24/rgrbs_0.png)

下载这个文件，解压到固定目录，先运行路径修复的exe，再运行主程序

![image-20220724004735930](http://img.ezsky.xyz/i/2022/07/24/s7wws_0.png)

运行好之后，将需要修改编码的文件拖拽到窗口内

![image-20220724004842139](http://img.ezsky.xyz/i/2022/07/24/sullr_0.png)

本来接下来应该是去断`MultiByteToWideChar`函数找`3A4`改成`utf-8`编码对应的`FDE9`的，类似大佬给的图这样

![image-20220724005334586](http://img.ezsky.xyz/i/2022/07/24/vsblm_0.png)

但是我一直不知道怎么断到正确的函数，因此索性直接ctrl+f，找`push 0x3A4`这个命令，一共6个结果，逐一修改成`push 0xFDE9`，然后按F9调试，如果还是乱码，就点下图的按钮重新去改别的，最终找到了两个需要修改的位置

![image-20220724005551300](http://img.ezsky.xyz/i/2022/07/24/x2khq_0.png)

修改好之后，右键，复制到可执行文件，所有修改

![image-20220724005758415](http://img.ezsky.xyz/i/2022/07/24/yjlhy_0.png)

全部复制

![image-20220724005841356](http://img.ezsky.xyz/i/2022/07/24/ystzm_0.png)

在新出现的窗口右键，保存文件

![image-20220724005917269](http://img.ezsky.xyz/i/2022/07/24/z8xuo_0.png)

取一个和源文件不一样的名字保存即可

![image-20220724005952943](http://img.ezsky.xyz/i/2022/07/24/zgn8h_0.png)

## 4 标题

标题所在的文件位于`system.arc`文件的`ipl._bp`，同样先用`GARBRO`提取出来

![image-20220724010236991](http://img.ezsky.xyz/i/2022/07/24/1oyu7g_0.png)

使用一个16进制编辑器打开（比如winhex）去找标题文本，逐一修改[16进制编码](http://www.txttool.com/t/?id=NDgy)（不能超出，可以补0，另外这里应该有些奇怪的逻辑，不是成片的文字片段直接改，建议ctrl+alt+h逐段文字修改）

![image-20220724010336768](http://img.ezsky.xyz/i/2022/07/24/1pkbes_0.png)

![image-20220724010553812](http://img.ezsky.xyz/i/2022/07/24/1quy01_0.png)

## 5 UI图标

系统图标位于`sysgrp.arc`文件下，用GARBRO对内部的文件右键，选择文件类型，图像

![image-20220724010829117](http://img.ezsky.xyz/i/2022/07/24/1shqb5_0.png)

可以看到能正常地读取

![image-20220724010908808](http://img.ezsky.xyz/i/2022/07/24/1sz0s3_0.png)

再对刚刚的文件右键，提取，另存为BMP，提取

![image-20220724010934307](http://img.ezsky.xyz/i/2022/07/24/1t4dbl_0.png)

用PS打开，修改好之后直接保存为BMP文件到exe的相同目录下，去掉BMP的后缀即可被正常读取

![image-20220724011124882](http://img.ezsky.xyz/i/2022/07/24/1u95de_0.png)

## 6 封包

多出来这么多修改好的文件，最终的汉化如何发布呢？

答案是把多出来的文件和exe一起封成新的exe

使用大佬推荐的[molebox](https://github.com/sudachen/Molebox)，打开exe程序

![image-20220724011516352](http://img.ezsky.xyz/i/2022/07/24/1wkzvh_0.png)

点这个图标添加好要打包在一起的文件（包括exe）

![image-20220724011646740](http://img.ezsky.xyz/i/2022/07/24/1xd24f_0.png)

点设置图标设置这两项

![image-20220724011610565](http://img.ezsky.xyz/i/2022/07/24/1x5de4_0.png)

再点击这个图标即可

![image-20220724011727634](http://img.ezsky.xyz/i/2022/07/24/1xug6v_0.png)
