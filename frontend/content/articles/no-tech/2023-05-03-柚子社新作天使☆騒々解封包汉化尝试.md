柚子社新作天使☆騒々 RE-BOOT!发布了正式版，尝试了一下解包封包，流程上应该不存在问题

## 1 文本汉化

由于新作采用了新的加密，[GARbro](https://github.com/morkt/GARbro)之类的工具无法直接解包XP3文件，因此需要通过[Krkrdump](https://github.com/crskycode/KrkrDump)先ctrl一遍，把所有用到的文本都dump下来

需要自行创建一个Json文件，内容如下（注释记得删掉）

```ini
{
    "loglevel": 1,
    "enableExtract": true,
    "outputDirectory": "E:\\games\\game\\dump",
    "rules": [
        "file://\\./.+?\\.xp3>(.+?\\..+$)",
        "archive://./(.+)",
        "arc://./(.+)",
        "bres://./(.+)"
   ],
    "includeExtensions": [
        ".scn"
   ],
    "excludeExtensions": [
        ".ogg"
   ],
    "decryptSimpleCrypt": true
}
```
其中，`outputDirectory`为输出地址，设置为自己的，`includeExtensions`为需要提取的后缀，`scn`指定只提取剧本文件，将游戏的可执行文件拖动到`KrkrDumpLoader.exe`，然后ctrl过去，所有读取到的文本就会导出到指定的目录

导出的scn文件不可直接读，需要通过程序读写：[KrKrZSceneManager](https://github.com/marcussacana/KrKrZSceneManager/releases)

打开`ScnEditorGUI.exe`，右键open然后选中指定scn，汉化完save即可

## 2 UI汉化

虽然也可以通过[Krkrdump](https://github.com/crskycode/KrkrDump)把tlg文件导出汉化，但是这回柚子社发布的体验版是无加密的，可以直接通过[GARbro](https://github.com/morkt/GARbro)解包，将提取出的png文件ps完之后，通过[KRKRTPC](https://github.com/poly000/galgametools/tree/d3fa44bf13e48757c57720ad6070e0e660e17f45/krkrtpc)转换png格式

![image-20230503183124686](https://s2.loli.net/2023/05/03/9a136JCfN5LBvnF.png)

是tlg5还是6就用winhex看文件头即可

## 3 脚本汉化

一样通过[Krkrdump](https://github.com/crskycode/KrkrDump)把tjs文件导出，然后通过[KrKrZSceneManager](https://github.com/marcussacana/KrKrZSceneManager/releases)右键TJS2-open打开指定文件即可

## 4 封包

GARBRO或者以下[工具](https://github.com/arcusmaximus/KirikiriTools/releases/tag/1.7)将修改过的文件封包成名为`unencrypted.xp3`的文件，并和[此链接](https://github.com/arcusmaximus/KirikiriTools/releases/tag/1.7)中的`version.dll`文件一起放入游戏根目录即可
