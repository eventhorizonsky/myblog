## 欢迎

这是我的个人博客，记录游戏评测、技术分享和动漫追番。

### 功能

- 📝 **文章** — Markdown 渲染的文章系统，支持分类筛选
- 🎮 **游戏** — 小黑盒游戏评测同步，带封面和评测内容
- 📺 **动漫** — 追番列表（即将通过 Bangumi API 集成）

### 关于

博客通过 Vite + Vue 3 构建，文章内容存储在 `doc/` 目录下的 Markdown 文件中。
同步脚本可以从小黑盒自动拉取帖子和游戏评测。
